# Discord map collection — 2026-09-22

Reviewed 114 rendered forum posts from the War Selection English community's map-collection channel. This is a source-backed archive, not a playtested recommendation list or a claim that all server history was exhaustively audited.

- 107 unique referenced map codes were selected: 100 new archives and 7 supplements to existing archives. Combined collection: 172 unique codes, preserving all 72 previously saved entries.
- Same-code reposts are merged. Different map codes are not silently merged based on similar names or geography. Known original / diplomacy / remix / player-count variants have provenance links.
- Austin confirms that his featured Stalingrad is adapted from the original. Yurky's `map-00200088` is separately archived with a link back to Austin's maintained `/maps/stalingrad` page; neither ruleset overwrites the other.
- Max's 2025-08-28 collection explicitly pairs eight no-mod originals with diplomacy editions. It takes precedence for edition labeling over older post titles containing “Original”; rule differences remain untested.
- Atlantic's two posts use the same map code but disagree about capacity. Capacity is unknown, and both sources remain linked. Training Map and Iron Clash also retain conflicting player-count warnings.
- Existing PVE author credits are preserved. A Discord publisher is not automatically treated as the creator. No mod code or replay code is imported as a map code.
- The two Austin Last Fortress codes remain linked with an unresolved-version note. The document's code is not replaced by the Discord code without confirmation.
- Chaos Mode was not selected because its author explicitly discouraged play due to bugs and balance. An unavailable North East America post reusing the World Map code, code-free posts, help/tutorial posts and a deleted/replaced post were not imported as new maps.
- Three original-post images were copied as local assets. Stalingrad's source image is labeled as a historical reference map, not an in-game screenshot. Other unarchived previews remain accessible through source links; no expiring media URLs are embedded.
- All new records are untested; no game-version compatibility, test date, ZIP download or missing author is invented. Discord source links may require login/server membership.

Implementation: static supplements keyed by map code; existing seed values and durable administrator overrides remain authoritative. No schema migration, database backfill, Discord message, follow/reaction or game-file edit.

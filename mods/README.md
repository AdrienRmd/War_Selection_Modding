# Mods

Index of all mods in this repository. Each mod lives in its own folder with its `.lua` file(s) and a `README.md` (see `README_TEMPLATE.md`).

| Mod                        | Description                                                                                     | Status |
|----------------------------|-------------------------------------------------------------------------------------------------|--------|
| [nuclear_bomb](nuclear_bomb/)             | Configurable nuclear bomb; four aircraft can build and drop one bomb each.       | Stable |
| [adjust_resources](adjust_resources/)     | Sets/scales map resource quantities (berries, fish, wheat, stone, iron, trees).  | Stable |
| [default_gameplay_functions](default_gameplay_functions/) | Three variants of the age/civilification gameplay function overrides (load one). | WIP |
| [victory_conditions](victory_conditions/) | Alternative victory/defeat rules: team annihilation, full win/loss engine, king mode. | WIP |
| [starting_resources](starting_resources/) | Configurable starting treasury resources per faction.                            | Stable |
